# API reference

This page lists the public surface of `@nepal-pay/core`. Gateway packages
export their factories (`createEsewa`, `createKhalti`, `createConnectIps`,
`createFonepay`, `createMockGateway`) and implement `GatewayAdapter`.

## Constants and guards

```ts
const PAYMENT_METHODS = [
  'esewa',
  'khalti',
  'connectips',
  'fonepay',
  'mock',
] as const

type PaymentMethod = (typeof PAYMENT_METHODS)[number]
isPaymentMethod(value: unknown): value is PaymentMethod

const PAYMENT_STATUSES = [
  'pending',
  'completed',
  'failed',
  'canceled',
  'expired',
  'unknown',
] as const

type PaymentStatus = (typeof PAYMENT_STATUSES)[number]
isPaymentStatus(value: unknown): value is PaymentStatus
```

## Reconciliation

```ts
const TERMINAL_PAYMENT_STATUSES = [
  'completed',
  'failed',
  'canceled',
  'expired',
] as const

type TerminalPaymentStatus = (typeof TERMINAL_PAYMENT_STATUSES)[number]
isTerminalPaymentStatus(value: unknown): value is TerminalPaymentStatus

interface PendingPayment {
  readonly order: Order
  readonly txnRef: TxnRef
}

type ReconcileReason = 'terminal' | 'exhausted' | 'timeout' | 'expired'

interface ReconcileOptions {
  readonly maxAttempts?: number // default 3
  readonly backoffMs?: number // default 250
  readonly maxBackoffMs?: number // default 5000
  readonly timeoutMs?: number // default 10000
  readonly expiresAt?: Date
  readonly now?: () => number
  readonly sleep?: (ms: number) => Promise<void>
  readonly retryOnError?: boolean
}

interface ReconcileResult {
  readonly payment: VerifiedPayment
  readonly status: PaymentStatus
  readonly attempts: number
  readonly resolved: boolean
  readonly reason: ReconcileReason
}

reconcile(
  gateway: GatewayAdapter,
  payment: PendingPayment,
  options?: ReconcileOptions
): Promise<ReconcileResult>
```

`reconcile()` retries while a payment is non-terminal (`pending` or `unknown`)
and stops on a terminal status, timeout, expiry, or attempt limit. It performs
one bounded run and does not schedule itself.

## Persistence

```ts
interface Payment {
  readonly orderId: string
  readonly amount: Money
  readonly status: PaymentStatus
  readonly txnRef: TxnRef
  readonly verifiedAt: Date
  readonly updatedAt: Date
  readonly raw?: Record<string, unknown>
}

interface PaymentStore {
  getPayment(orderId: string): Promise<Payment | null>
  savePayment(payment: Payment): Promise<void>
  acquireIdempotencyKey(key: string): Promise<boolean>
}

paymentFromVerified(payment: VerifiedPayment, now?: Date): Payment
createInMemoryPaymentStore(): InMemoryPaymentStore

class InMemoryPaymentStore implements PaymentStore {
  getPayment(orderId: string): Promise<Payment | null>
  savePayment(payment: Payment): Promise<void>
  acquireIdempotencyKey(key: string): Promise<boolean>
  clear(): void
}
```

`paymentFromVerified` rejects anything not sealed by `verify()` with
`UNVERIFIED_PAYMENT`.


RSA helpers used by connectIPS:

```ts
importPkcs8PrivateKey(pem: string): Promise<RsaPrivateKey>
importSpkiPublicKey(pem: string): Promise<RsaPublicKey>
rsaSha256Sign(data: string, key: RsaPrivateKey): Promise<string>
rsaSha256Verify(data: string, signature: string, key: RsaPublicKey): Promise<boolean>
```

All signature comparisons are constant time. `safeBase64Decode` throws
`INVALID_BASE64` on malformed input.

## Errors

```ts
class NepalPayError extends Error {
  readonly code?: PaymentErrorCode
  readonly details?: Record<string, unknown>
}
class PaymentError extends NepalPayError {}
class VerificationError extends NepalPayError {}
class ConfigurationError extends NepalPayError {}
class MoneyError extends NepalPayError {}
```

`PAYMENT_ERROR_CODES`, `isPaymentErrorCode()`, and `PAYMENT_STATUSES` are also
exported. See [Errors](/docs/core/errors) for the full code table.
