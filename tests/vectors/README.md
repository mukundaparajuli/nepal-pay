# Shared Test Vectors

JSON fixtures consumed by `tests/vectors/vectors.test.ts`. Every file here is
executed against the real gateway implementations — nothing is decorative.

## Layout

| Path                             | Contents                                                                              | Consumed by                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `signatures/schemes.json`        | which gateway signs callbacks, algorithm/encoding/constant-time flags                 | scheme export checks                                                                    |
| `signatures/esewa-demo.json`     | message + HMAC-SHA256(base64) vectors for eSewa `signFields`                          | `buildSignatureMessage`, `signFields`, `verifySignedFields` (incl. tampered rejections) |
| `signatures/mock-hmac.json`      | message + HMAC-SHA256(hex) vectors for the mock signer, plus cross-checks             | `buildMockSignatureMessage`, `signMockCallback`, `verifyMockSignature`                  |
| `callbacks/*.json`               | a valid callback request per gateway, its parsed expectations, and malformed variants | each gateway's `parseCallback`; every malformed variant must throw `MALFORMED_CALLBACK` |
| `amounts/precision-scaling.json` | decimal → units → paisa scaling at precision 0/1/2                                    | `moneyFromDecimal`, `moneyToDecimal`, `khaltiPaisaToMoney`                              |
| `amounts/boundaries.json`        | min/max/safe-integer edges with per-gateway acceptance                                | mock + Khalti `createCheckout` accept/reject                                            |
| `amounts/invalid.json`           | inputs that must throw, with the expected error code                                  | `moneyFromDecimal`, `createMoney`, `khaltiPaisaToMoney`                                 |
| `statuses/*.json`                | gateway-native status → unified status cases                                          | `mapEsewaStatus`, `mapKhaltiStatus`, `mapMockStatus`, `PAYMENT_STATUSES`                |

## Provenance

- eSewa signature vectors: field values from `tests/fixtures/esewa/callback-complete.json`,
  signatures computed with the documented sandbox secret `8gBm/:&EnhH.1/q`.
- Khalti callback vectors: copied from `tests/fixtures/khalti/*.json`
  (docs-derived from https://docs.khalti.com/khalti-epayment).
- Mock vectors: generated by the mock package's own signer with `vector-secret`.

Adding a gateway? Add a vector file for each directory here and a driver under
`tests/conformance/drivers/`; the conformance suite then runs the full
contract (checkout → callback → verify → status → errors) automatically.
