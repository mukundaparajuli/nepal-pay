# Nepal Payments

Stateless Nepal payment gateway SDK monorepo.

## Packages

- `@nepal-payments/core` - Core types, utilities, and interfaces
- `@nepal-payments/esewa` - eSewa payment gateway integration
- `@nepal-payments/khalti` - Khalti payment gateway integration

## Apps

- `apps/next-example` - Next.js usage example
- `apps/express-example` - Express.js usage example

## Development

```bash
pnpm install
pnpm build
pnpm test
pnpm lint
pnpm typecheck
```
